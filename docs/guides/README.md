# User guides

These guides walk a repository owner through a task. When a change affects a user's steps, update the guide for that task.

- [Manage one repository label](manage-labels.md) follows a label from its exported ID through a reviewed change.
- [Plan and apply with GitHub Actions](github-actions.md) covers App credentials, the published Action and the [copyable workflows](../../examples/github-actions/README.md).
- [Protect the apply path](protect-apply.md) explains how branch rules and Environment approvals control who can apply settings.

The [public references](../references/README.md) define the exact command options, Action inputs and YAML fields used in these procedures.
