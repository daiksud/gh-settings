# Consumer workflow examples

These examples are written for repositories that use gh-settings. The [GitHub Actions examples](github-actions/README.md) explain where to copy the workflows, which GitHub App permissions they need and when they run.

Edit the [PR workflow](github-actions/settings-pr.yml) to change how the example plans proposed settings, or the [main workflow](github-actions/settings-main.yml) to change how it applies merged settings. When changing either example, check the [setup guide](../docs/guides/github-actions.md) and the [workflow tests](../tests/github-actions/README.md) against the same behavior. This project's own CI and settings workflows are documented in the [repository automation directory guide](../.github/CONTENTS.md).
